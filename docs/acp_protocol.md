# Agent Communication Protocol (ACP) Reference

> [!NOTE]
> **Planned Specification**: This document specifies the target JSON-RPC interface schema for external IDE plugins (JetBrains, VS Code).
> For current interactive command-line usage, refer to [`docs/cli_reference.md`](cli_reference.md).

The **Agent Communication Protocol (ACP)** enables IDEs (such as JetBrains and VS Code), CI pipelines, and external developer tools to orchestrate Coddy as a headless or streaming agentic service.

## 1. ACP Request Payload Schema

```json
{
  "protocol_version": "1.0",
  "command": "trigger_workflow | update_state | get_status",
  "payload": {
    "workflow_id": "uuid",
    "input_data": {}, 
    "current_artifact": {}
  }
}
```

### Supported Commands

#### `trigger_workflow`
Starts a new recursive decomposition workflow.
- `workflow_id`: Unique identifier generated by the IDE.
- `input_data.prompt`: Raw user task prompt.
- `input_data.project_name` (optional): Desired project name.

#### `update_state`
Supplies human input or decision to an awaiting workflow state.
- `input_data.action`: One of:
  - `"answer_questions"`: Contains map of question $\to$ answer.
  - `"approve_spec"`: Signals human approval of the Specification, advancing to Step 5 (Plan).
  - `"reject_spec"`: Signals rejection (`mode`: `minor_tweak` or `scope_change`) with feedback text.
  - `"approve_plan"`: Signals human approval of the Plan, completing the workflow.
  - `"reject_plan"`: Signals rejection (`mode`: `minor_tweak` or `scope_change`) with feedback text.

#### `get_status`
Polls current execution state and active artifact.

---

## 2. ACP Response Schema

```json
{
  "protocol_version": "1.0",
  "workflow_id": "uuid",
  "status": "awaiting_clarification | awaiting_spec_approval | awaiting_plan_approval | completed | error",
  "step": "Current step name",
  "message": "Human-readable summary message",
  "questions": ["Optional list of clarification questions"],
  "artifact_json": {},
  "artifact_markdown": "Optional Markdown rendered string"
}
```
